Compteur de jours

Calcule les jours restants jusqu'à ton événement.

Entre deux dates, puis l'application affiche immédiatement la différence en jours. Elle fonctionne aussi hors ligne après installation.

Résultat

--

Entre deux dates pour voir le nombre de jours.

Exemple : aujourd'hui comme point de départ, puis la date de ton concert, voyage ou rendez-vous.

Tu peux installer cette application sur Android depuis Chrome avec le bouton ci-dessous quand il apparaît.

Astuce : une fois publiée en HTTPS, Chrome Android peut proposer l'installation depuis le menu ou via le bouton intégré.

Version PWA : manifest, icônes et service worker inclus.
